📘 DAPE-1400 – Java Programming Project
This repository contains the code and project files for DAPE-1400, a Java programming assignment completed as part of the course DAPE-1400: Java Programmering. The project demonstrates core Java concepts, object-oriented design, and basic application development using IntelliJ and Git.

🧠 About
The project includes:
Source code developed in Java (100% Java codebase).
IntelliJ IDEA project configuration files.
Example classes and implementation files for assignments in the course.
It was created as part of required coursework and showcases skills in Java programming fundamentals such as classes, methods, data structures, and program logic.

🚀 Features
✔️ Java source code for tasks and assignments
✔ Structured project setup compatible with IntelliJ IDEA
✔ Clean implementation of core Java concepts
✔ Easy to clone and review

🛠️ Getting Started
To run this project locally:
Clone the repository
git clone https://github.com/Abdisharif107/DAPE-1400.git
Open in IntelliJ
Choose Open → select the project folder.
Build and run
Use IntelliJ’s Run configuration to compile and execute the Java application.
